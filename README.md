# prompt-injection-detection-ml
Detecção de ataques de prompt injection em LLMs com ML clássico: kNN, Árvore, Perceptron, SVM e SDA sobre embeddings TF-IDF e RoBERTa. Melhor resultado: SVM + RoBERTa (F1 0,88).
